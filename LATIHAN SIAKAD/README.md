# Kode SIAKAD — Potongan per Bagian + Final

- `01_login.py`: fungsi tampilan dan proses login saja.
- `02_beranda.py`: beranda, navigasi, dan scroll saja.
- `03`–`08`: masing-masing konfigurasi dan fungsi tabel/data modul yang disebut pada nama file. Kode CRUD tabel dipakai bersama oleh aplikasi final.
- `09_logout.py`: fungsi logout saja.
- `FINAL/final_siakad.py`: seluruh aplikasi yang digabung, untuk dijalankan.

## Menjalankan aplikasi final
1. Letakkan `database.py` milik proyekmu di folder `FINAL` (file ini tidak ada pada lampiran yang tersedia, jadi koneksi database belum bisa diuji).
2. Pastikan database MySQL `siakad` dan tabel-tabelnya sudah dibuat sesuai kode `database.py`.
3. Instal dependensi: `pip install mysql-connector-python`.
4. Jalankan: `python final_siakad.py`.

Cuplikan tahap dibuat dari kode aplikasi final yang disusun berdasarkan kode yang tersedia.
